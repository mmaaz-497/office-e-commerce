# Tokoshopee

A bilingual (Indonesian-default) single-product storefront for "Slippers Gemoy", with Midtrans
online payment, COD, and a single-operator admin area.

Built via Spec-Driven Development — see `specs/001-tokoshopee-storefront/` for the spec, plan,
research, data model and task breakdown, and `specs/001-tokoshopee-storefront/quickstart.md` for
local setup, environment variables and the pre-launch release checklist.
