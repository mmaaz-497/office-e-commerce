Keep frontend performance in mind during the redesign.

Avoid changes that negatively affect:

- LCP
- CLS
- FCP
- Core Web Vitals

Optimize where appropriate:

- Image loading
- Image dimensions
- Lazy loading
- Component rendering
- Fonts
- CSS
- JavaScript
- Large dependencies
- Unnecessary animations

Do not sacrifice performance simply to make the website visually attractive.
